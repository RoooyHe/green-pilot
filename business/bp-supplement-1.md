# 商业计划补充

> \[!TIP] 目标
> 根据训练营 Week 3-4 的实战要求，完善商业计划书的核心模块。

***

## 1. 强化核心定位

**当前情况**：市场分析文档中明确提到，如果只做"智慧大棚管理系统"或单纯的 SaaS 平台是没有竞争力的。

**完善建议**：

> \[!IMPORTANT] 调整方向
> 将定位调整为 **"机器人 + AI Agent 协同决策平台"**。

由于 OpenCamp 训练营的核心主题是"农业机器人"，商业计划书需要：

- 突出**机器人作为执行者与感知者，AI 作为大脑**的协同闭环
- 弱化纯软件 SaaS 的刻板印象
- 将机器人联动作为核心卖点前置

***

## 2. 补充商业模式画布

**当前情况**：商业计划书列出了 SaaS 按温室收费的标准（如 500 元/月/棚）以及目标市场，但较为单薄。

**完善建议**：

> \[!TIP] 训练营 Week 3 要求
> 项目必须具备**商业模式画布（Business Model Canvas）和商业可行性分析**。

需要补充：

| 模块          | 内容     |
| ----------- | ------ |
| 客户获取成本（CAC） | 预估获客成本 |
| 生命周期价值（LTV） | 客户长期价值 |
| 投入产出比       | 具体财务指标 |
| 盈利周期        | 预计回本时间 |
| 财务预测        | 详细收入预测 |

***

## 3. 补充团队介绍

**当前情况**：目前的商业部分完全没有提及团队成员。

**完善建议**：

> \[!WARNING] 核心项
> 训练营 Week 4 专家初筛标准中，**"团队能力"是三大核心标准之一**（技术可行性 + 场景匹配度 + 团队能力）。

必须增加团队介绍，突出复合能力：

| 能力维度 | 说明          |
| ---- | ----------- |
| 技术能力 | AI/IoT 技术背景 |
| 农业知识 | 农学专业知识      |
| 商业能力 | 商业化与运营能力    |

***

## 4. 细化市场进入策略

**当前情况**：列出了目标市场（如农业科研院所、农业园区等）。

**完善建议**：

结合 `platform-scenario.md` 中提到的"京瓦中心"四大场景：

- 高 GABA 品种筛选
- 草莓繁育

详细说明：

1. 如何利用这些真实需求场景获取**第一批种子客户（标杆案例）**

## 5. 补充融资与资金规划

**当前情况**：缺少资金规划。

**完善建议**：

> \[!TIP] 训练营孵化支持
> 优胜项目可获得最高 **50 万元启动资金**，最长 3 年 0 租金工位。

应设立专门的"融资与资金规划"板块：

| 资金用途    | 占比建议 |
| ------- | ---- |
| 研发投入    | 40%  |
| 机器人硬件采购 | 25%  |
| 市场拓展    | 20%  |
| 运营储备    | 15%  |
