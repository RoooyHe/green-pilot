# 市场分析

> [!WARNING] 核心问题
> 如果只是做"智慧大棚管理系统"，没有任何优势，甚至没有竞争力。

因为寿光已经发展十几年了，这个赛道已经非常成熟。

## 行业现状

目前寿光主流系统已具备：

| 类别 | 功能 |
|------|------|
| 传感器采集 | 温湿度、光照、CO₂ |
| 移动端 | 手机 App 控制 |
| 自动化 | 自动卷帘、通风、补光 |
| 水肥管理 | 水肥一体机 |
| 监控预警 | 视频监控、AI 预警、报警推送 |
| 数据管理 | 数据大屏、种植档案 |
| 智能化 | 巡检机器人、AI 管理系统 |

> [!TIP] 行业标配
> 手机控制风机、自动灌溉、自动补光、自动报警 — 这些已经是行业标配。

## 差异化策略

> [!TIP] 换赛道，而不是卷功能
> 不要卖控制系统（Control），而是卖 **AI 决策层（Intelligence Layer）**。

### 传统模式

```text
传感器 → PLC → 控制器 → APP
```

温度高了 → 打开风机 → 结束。

### GreenPilot 模式

```text
机器人 → IoT → 数字孪生 → AI Agent → 多Agent讨论 → 经营建议 → 控制系统执行
```

> [!IMPORTANT] 核心定位
> 控制系统不是你的产品，**AI 才是你的产品**。

---

## 实例对比

### 传统系统

```text
温度：34℃
→ 打开风机
```

### GreenPilot

```text
今天下午有雷阵雨，未来两小时光伏发电下降40%。

建议：
- 提前完成补光
- 推迟灌溉（未来湿度会上升，避免番茄裂果）

预计：节约电费72元，降低裂果率3%

是否执行？
```

> 它回答的是 **为什么**。

---

## Agent 协同决策

AI Agent 可以讨论并形成决策：

| Agent | 观点 | 原因 |
|-------|------|------|
| Energy Agent | 今天应该补光 | — |
| Crop Agent | 不建议 | 番茄已达到 DLI（每日光积分） |
| Carbon Agent | 成本高 | 今天是峰电 |
| Weather Agent | 自然光够 | 下午晴 |

> [!TIP] LLM 总结
> 不建议补光。预计节约 17% 电费，产量影响 <0.5%。

这就是 **Agent 协同决策**，传统系统基本没有这一层。

## 第二个优势：农业 Copilot

传统系统控制设备，GreenPilot 管理知识。

建立知识库：番茄、草莓、黄瓜、专家经验、论文、实验数据。

AI 可以回答：

- 为什么最近裂果？
- 为什么最近徒长？
- 为什么 EC 要降？
- 为什么下午不能灌水？

> [!TIP] 差异化
> 不是告诉你 pH 是多少，而是告诉你**为什么**。

这就是 **农业 Copilot**。

---

## 第三个优势：科研支持

寿光系统主要面向种植，而京瓦中心有特殊需求：**科研**。

AI 可以自动：统计、分析、画图、生成论文图表、生成结题报告。

这套能力普通智慧大棚系统通常不是核心卖点，但科研单位却很需要。

## 进一步建议

> [!TIP] 训练营主题是农业机器人
> 单纯做 SaaS 平台可能仍然不够。

建议定位调整为：**机器人 + AI Agent 协同决策平台**

- 巡检机器人负责采集环境、图像和设备状态
- AI Agent 负责融合机器人、传感器、天气和历史数据
- 输出的不是"开风机"，而是"今天是否巡检、是否补光、是否采摘、是否安排人员"
- 通过辰龙机器人平台把决策下发给机器人或控制设备

> [!IMPORTANT] 核心逻辑
> **机器人是执行者，AI 是决策者。** 真正的竞争壁垒不是"能不能控制一个风机"，而是"能不能让整个农业机器人系统变得更聪明、更省人、更会决策"。
