## Week 1：技术筑基

> 7月13日 - 7月19日

### 本周目标

| 维度 | 目标 |
|------|------|
| 技术学习 | 掌握无人机、采摘机器人、辰龙系统的核心技术原理 |
| 硬件搭建 | 完成基础传感器套件采购与环境搭建 |
| 代码实践 | 跑通 MCP 协议与辰龙平台的基础对接 |

### 详细计划

#### Day 1-2：无人机技术（7月13-14日）

- 了解主流农业无人机平台（大疆、极飞）
- 研究无人机航测与图像采集方案
- 整理无人机技术与 GreenPilot 的结合点

#### Day 3-4：采摘机器人（7月15-16日）

- 研究成熟度识别算法（YOLO、图像分割）
- 了解机械臂选型（轻量级、低成本方案）
- 整理采摘机器人与 GreenPilot 的结合点

#### Day 5-7：辰龙系统实战（7月17-19日）

- 获取辰龙平台 API/SDK 文档
- 搭建 MCP Server 基础框架
- 实现 `get_robot_location()` 基础接口
- 实现 `get_camera_frame()` 基础接口

### 硬件采购清单

| 硬件 | 用途 | 预算 | 优先级 |
|------|------|------|--------|
| 温湿度传感器 | 环境数据采集 | 50-200 元 | P0 |
| 光照传感器 | 补光决策 | 100-300 元 | P0 |
| CO₂ 传感器 | 环境监测 | 200-500 元 | P1 |
| 树莓派/ESP32 | IoT 网关 | 200-500 元 | P0 |
| 辰龙机器人 | 核心执行平台 | 联系辰龙 | P0 |

### 周末检查点

- [ ] 完成三大技术方向的调研笔记
- [ ] 硬件采购清单确认并下单
- [ ] MCP Server 基础框架搭建完成
- [ ] 辰龙平台对接方案文档完成

## Week 2：场景深耕

> 7月20日 - 7月26日

### 本周目标

| 维度 | 目标 |
|------|------|
| 需求分析 | 深入理解京瓦中心四大场景的真实需求 |
| 场景定义 | 明确 GreenPilot 的核心应用场景 |
| 原型设计 | 完成核心功能的原型设计 |

### 详细计划

#### Day 1-2：京瓦中心需求调研（7月20-21日）

- 参与京瓦中心专家分享（设施农业创新及传感器国产化）
- 研究四大场景的技术需求：
  - 高 GABA 番茄品种筛选
  - 草莓繁育
  - 鲜酒花生产
  - AI 试验管家

#### Day 3-4：设施农业企业需求（7月22-23日）

- 参与设施农业企业、果农或专家分享
- 研究巡检、采摘等真实需求
- 整理企业端痛点与解决方案

#### Day 5-7：原型设计（7月24-26日）

- 完成核心功能原型设计
- 设计 MCP 工具接口规范
- 搭建 RAG 知识库基础框架
- 完成前端大屏原型

### 周末检查点

- [ ] 完成需求调研报告
- [ ] 核心功能原型设计完成
- [ ] MCP 工具接口规范文档完成
