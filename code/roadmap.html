    #五周训练营路线图

    TIP

    时间：7月13日 - 8月16日 目标：从技术验证到商业落地，完成 GreenPilot 的 MVP 原型

    #总览

    周次日期主题核心产出
    Week 17/13-7/19技术筑基技术调研、硬件采购、MCP 框架
    Week 27/20-7/26场景深耕需求分析、场景定义、原型设计
    Week 37/27-8/2商业赋能商业画布、财务预测、路演材料

    #Week 1：技术筑基

    7月13日 - 7月19日

    #本周目标

    维度目标
    技术学习掌握无人机、采摘机器人、辰龙系统的核心技术原理
    硬件搭建完成基础传感器套件采购与环境搭建
    代码实践跑通 MCP 协议与辰龙平台的基础对接

    #详细计划

    #Day 1-2：无人机技术（7月13-14日）

    • 了解主流农业无人机平台（大疆、极飞）
    • 研究无人机航测与图像采集方案
    • 整理无人机技术与 GreenPilot 的结合点

    #Day 3-4：采摘机器人（7月15-16日）

    • 研究成熟度识别算法（YOLO、图像分割）
    • 了解机械臂选型（轻量级、低成本方案）
    • 整理采摘机器人与 GreenPilot 的结合点

    #Day 5-7：辰龙系统实战（7月17-19日）

    • 获取辰龙平台 API/SDK 文档
    • 搭建 MCP Server 基础框架
    • 实现 get_robot_location() 基础接口
    • 实现 get_camera_frame() 基础接口

    #硬件采购清单

    硬件用途预算优先级
    温湿度传感器环境数据采集50-200 元P0
    光照传感器补光决策100-300 元P0
    CO₂ 传感器环境监测200-500 元P1
    树莓派/ESP32IoT 网关200-500 元P0
    辰龙机器人核心执行平台联系辰龙P0

    #周末检查点

    • 完成三大技术方向的调研笔记
    • 硬件采购清单确认并下单
    • MCP Server 基础框架搭建完成
    • 辰龙平台对接方案文档完成

    #Week 2：场景深耕

    7月20日 - 7月26日

    #本周目标

    维度目标
    需求分析深入理解京瓦中心四大场景的真实需求
    场景定义明确 GreenPilot 的核心应用场景
    原型设计完成核心功能的原型设计

    #详细计划

    #Day 1-2：京瓦中心需求调研（7月20-21日）

    • 参与京瓦中心专家分享（设施农业创新及传感器国产化）
    • 研究四大场景的技术需求：
      • 高 GABA 番茄品种筛选
      • 草莓繁育
      • 鲜酒花生产
      • AI 试验管家

    #Day 3-4：设施农业企业需求（7月22-23日）

    • 参与设施农业企业、果农或专家分享
    • 研究巡检、采摘等真实需求
    • 整理企业端痛点与解决方案

    #Day 5-7：原型设计（7月24-26日）

    • 完成核心功能原型设计
    • 设计 MCP 工具接口规范
    • 搭建 RAG 知识库基础框架
    • 完成前端大屏原型

    #周末检查点

    • 完成需求调研报告
    • 核心功能原型设计完成
    • MCP 工具接口规范文档完成
    • RAG 知识库基础框架搭建完成

    #Week 3：商业赋能

    7月27日 - 8月2日

    #本周目标

    维度目标
    商业画布完成商业模式画布（Business Model Canvas）
    财务预测完成商业可行性分析与财务预测
    路演材料完成路演 PPT 与演示 Demo

    #详细计划

    #Day 1-2：商业模式画布（7月27-28日）

    • 完成商业模式画布九大模块：
      • 价值主张
      • 客户细分
      • 渠道通路
      • 客户关系
      • 收入来源
      • 核心资源
      • 关键业务
      • 重要合作
      • 成本结构

    #Day 3-4：财务预测（7月29-30日）

    • 完成客户获取成本（CAC）与生命周期价值（LTV）预估
    • 完成投入产出比、盈利周期分析
    • 完成详细财务预测

    #Day 5-7：路演材料（7月31日-8月2日）

    • 完成路演 PPT 制作
    • 准备 Demo 演示（MCP + 辰龙机器人）
    • 团队路演训练

    #周末检查点

    • 商业模式画布完成
    • 财务预测文档完成
    • 路演 PPT 完成
    • Demo 演示准备就绪

    8月3日 - 8月9日

    #本周目标

    维度目标
    方案提交完成初步方案并提交
    专家评审准备专家评审答辩
    团队组建完成团队组建与分工

    #详细计划

    #Day 1-2：方案完善（8月3-4日）

    • 完善技术方案文档
    • 完善商业计划书
    • 准备团队介绍材料

    #Day 3-4：专家评审（8月5-6日）

    • 参与专家评审答辩
    • 回答技术可行性问题
    • 回答场景匹配度问题
    • 回答团队能力问题

    #Day 5-7：团队组建（8月7-9日）

    • 确认团队成员与分工
    • 准备线下实战计划
    • 等待入围名单公布

    #周末检查点

    • 初步方案提交完成
    • 专家评审答辩完成
    • 团队组建确认
    • 入围名单公布（目标：20-30 支团队）
