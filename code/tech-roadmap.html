    #Week 1：IoT 接入层（7/13-7/19）

    #技术目标

    • 搭建 MQTT Broker（EMQX）
    • 实现传感器数据采集与上报
    • 完成数据存储（Redis + TimescaleDB）

    #详细任务

    #Day 1-2：MQTT 环境搭建

    任务技术选型产出
    部署 EMQXDocker / 云服务MQTT Broker 运行
    配置 Topic 规范greenhouse/{棚区}/sensor/{类型}Topic 设计文档
    编写发布脚本Python / Node.js模拟传感器数据

    #Day 3-4：数据存储

    任务技术选型产出
    Redis 部署Docker实时数据缓存
    TimescaleDB 部署Docker时序数据存储
    数据写入脚本Node.jsMQTT → Redis/TimescaleDB

    #Day 5-7：传感器接入

    任务硬件产出
    温湿度传感器DHT22 / SHT30数据上报验证
    光照传感器BH1750数据上报验证
    CO₂ 传感器MH-Z19B数据上报验证

    #技术产出

    • EMQX Broker 运行
    • 传感器数据上报脚本
    • Redis + TimescaleDB 数据存储
    • IoT 接入层文档

    #Week 2：MCP 协议层（7/20-7/26）

    #技术目标

    • 实现 MCP Server 框架
    • 封装传感器读取接口
    • 封装设备控制接口

    #详细任务

    #Day 1-2：MCP Server 框架

    任务技术选型产出
    MCP Server 初始化Node.js / Python项目框架
    Tool 注册机制MCP SDKTool 注册接口
    错误处理—统一错误格式

    #Day 3-4：传感器 MCP 工具

    工具功能接口
    get_sensor_data获取传感器实时数据device_id: string
    get_weather获取天气数据location: string
    get_energy_status获取能源状态棚区: string

    #Day 5-7：设备控制 MCP 工具

    工具功能接口
    control_device控制设备开关device_id, action
    set_environment设置环境参数device_id, value
    robot_navigate机器人导航target_x, target_y

    #技术产出

    • MCP Server 框架
    • 传感器读取 Tool（3个）
    • 设备控制 Tool（3个）
    • MCP 接口文档

    #Week 3：AI Agent 层（7/27-8/2）

    #技术目标

    • 搭建 Agent 框架（LangGraph）
    • 实现多模态图像识别
    • 实现 Agent 决策链

    #详细任务

    #Day 1-2：Agent 框架搭建

    任务技术选型产出
    LangGraph 初始化LangGraphAgent 框架
    Tool 绑定MCP ClientAgent 可调用 MCP 工具
    状态管理LangGraph State会话状态管理

    #Day 3-4：多模态图像识别

    任务技术选型产出
    图像采集Camera MCP机器人摄像头图像
    图像理解GPT-4o / Qwen-VL作物状态识别
    结果解析JSON结构化输出

    #Day 5-7：Agent 决策链

    Agent职责工具
    Environment Agent环境监测与调控传感器 MCP、设备控制 MCP
    Energy Agent能源优化调度能源 MCP、天气 MCP
    Robot Agent机器人巡检机器人 MCP、摄像头 MCP

    #技术产出

    • LangGraph Agent 框架
    • 多模态图像识别模块
    • 3 个核心 Agent 实现
    • Agent 决策链文档
