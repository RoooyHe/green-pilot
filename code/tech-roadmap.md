## Week 1：IoT 接入层（7/13-7/19）

### 技术目标

- 搭建 MQTT  Broker（EMQX）
- 实现传感器数据采集与上报
- 完成数据存储（Redis + TimescaleDB）

### 详细任务

#### Day 1-2：MQTT 环境搭建

| 任务          | 技术选型                          | 产出             |
| ----------- | ----------------------------- | -------------- |
| 部署 EMQX     | Docker / 云服务                  | MQTT Broker 运行 |
| 配置 Topic 规范 | `greenhouse/{棚区}/sensor/{类型}` | Topic 设计文档     |
| 编写发布脚本      | Python / Node.js              | 模拟传感器数据        |

#### Day 3-4：数据存储

| 任务             | 技术选型    | 产出                       |
| -------------- | ------- | ------------------------ |
| Redis 部署       | Docker  | 实时数据缓存                   |
| TimescaleDB 部署 | Docker  | 时序数据存储                   |
| 数据写入脚本         | Node.js | MQTT → Redis/TimescaleDB |

#### Day 5-7：传感器接入

| 任务      | 硬件            | 产出     |
| ------- | ------------- | ------ |
| 温湿度传感器  | DHT22 / SHT30 | 数据上报验证 |
| 光照传感器   | BH1750        | 数据上报验证 |
| CO₂ 传感器 | MH-Z19B       | 数据上报验证 |

### 技术产出

- [ ] EMQX Broker 运行
- [ ] 传感器数据上报脚本
- [ ] Redis + TimescaleDB 数据存储
- [ ] IoT 接入层文档

## Week 2：MCP 协议层（7/20-7/26）

### 技术目标

- 实现 MCP Server 框架
- 封装传感器读取接口
- 封装设备控制接口

### 详细任务

#### Day 1-2：MCP Server 框架

| 任务             | 技术选型             | 产出        |
| -------------- | ---------------- | --------- |
| MCP Server 初始化 | Node.js / Python | 项目框架      |
| Tool 注册机制      | MCP SDK          | Tool 注册接口 |
| 错误处理           | —                | 统一错误格式    |

#### Day 3-4：传感器 MCP 工具

| 工具                  | 功能        | 接口                  |
| ------------------- | --------- | ------------------- |
| `get_sensor_data`   | 获取传感器实时数据 | `device_id: string` |
| `get_weather`       | 获取天气数据    | `location: string`  |
| `get_energy_status` | 获取能源状态    | `棚区: string`        |

#### Day 5-7：设备控制 MCP 工具

| 工具                | 功能     | 接口                   |
| ----------------- | ------ | -------------------- |
| `control_device`  | 控制设备开关 | `device_id, action`  |
| `set_environment` | 设置环境参数 | `device_id, value`   |
| `robot_navigate`  | 机器人导航  | `target_x, target_y` |

### 技术产出

- [ ] MCP Server 框架
- [ ] 传感器读取 Tool（3个）
- [ ] 设备控制 Tool（3个）
- [ ] MCP 接口文档

## Week 3：AI Agent 层（7/27-8/2）

### 技术目标

- 搭建 Agent 框架（LangGraph）
- 实现多模态图像识别
- 实现 Agent 决策链

### 详细任务

#### Day 1-2：Agent 框架搭建

| 任务            | 技术选型            | 产出               |
| ------------- | --------------- | ---------------- |
| LangGraph 初始化 | LangGraph       | Agent 框架         |
| Tool 绑定       | MCP Client      | Agent 可调用 MCP 工具 |
| 状态管理          | LangGraph State | 会话状态管理           |

#### Day 3-4：多模态图像识别

| 任务   | 技术选型             | 产出       |
| ---- | ---------------- | -------- |
| 图像采集 | Camera MCP       | 机器人摄像头图像 |
| 图像理解 | GPT-4o / Qwen-VL | 作物状态识别   |
| 结果解析 | JSON             | 结构化输出    |

#### Day 5-7：Agent 决策链

| Agent             | 职责      | 工具               |
| ----------------- | ------- | ---------------- |
| Environment Agent | 环境监测与调控 | 传感器 MCP、设备控制 MCP |
| Energy Agent      | 能源优化调度  | 能源 MCP、天气 MCP    |
| Robot Agent       | 机器人巡检   | 机器人 MCP、摄像头 MCP  |

### 技术产出

- [ ] LangGraph Agent 框架
- [ ] 多模态图像识别模块
- [ ] 3 个核心 Agent 实现
- [ ] Agent 决策链文档
